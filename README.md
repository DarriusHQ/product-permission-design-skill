# Product Permission Design Skill

面向产品经理的权限体系梳理 skill，帮助基于实际业务流程设计角色、页面、功能、数据范围与授权生命周期，并输出可评审的权限矩阵。

## 使用

将本仓库克隆到技能目录，或将仓库中的 `SKILL.md`、`agents/` 和 `references/` 一并复制到支持 Agent Skills 的环境，再使用 `$product-permission-design` 调用。请提供产品 PRD、流程、原型及已有权限规则；缺失信息会列为待确认。

## 包含内容

- `SKILL.md`：通用权限梳理方法与检查项。
- `references/matrix-template.md`：权限目录、角色矩阵和验收模板。
- `agents/openai.yaml`：技能界面信息。

产品或组织专属规则应由使用方根据真实资料另行提供；示例不代表真实授权实现。
